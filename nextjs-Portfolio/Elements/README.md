## 🎨 Portfolio Elements

A curated collection of high-impact portfolio themes built with Next.js, focused on layout clarity, motion-first interactions, and real-world frontend architecture. Each theme explores a different visual personality — from minimal and content-driven to expressive and animation-heavy.

**🔗 Live demo**: `https://portfolio-elements-omega.vercel.app/`

---

## 🚀 Project overview

Portfolio Elements is a **frontend-focused UI showcase** built to demonstrate:

- ✨ **Clean and modern UI layouts**
- 🎞️ **Animation-driven interactions**
- 🧱 **Scalable and reusable component architecture**

Each theme represents a unique portfolio style suitable for developers, designers, and product-based showcases.

---

## 🧩 Tech stack

- **⚙️ Framework**
  - 🟢 Next.js 16
  - ⚛️ React 19

- **🎨 Styling**
  - 🎯 Tailwind CSS
  - 🧩 `tailwind-merge`
  - 🧠 `class-variance-authority`

- **🛠 Utilities**
  - 🧪 `clsx`
  - 🎨 `lucide-react`
