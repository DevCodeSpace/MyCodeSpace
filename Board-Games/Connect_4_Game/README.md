# 🎮 Connect 4 Game

A modern Flutter-based implementation of the classic **Connect 4 (Four-in-a-Row)** board game. Play against an AI opponent or challenge a friend locally with a smooth, responsive, and visually polished mobile experience.

## 📌 Overview

Connect 4 Game brings the timeless strategy board game to mobile devices with an intuitive interface and engaging gameplay. Players take turns dropping discs into a grid, aiming to connect four in a row horizontally, vertically, or diagonally.

The app supports both **Single-player (AI)** and **2-player modes**, making it suitable for casual play as well as strategic challenges.

---

## 🚀 Features

- 🤖 Single-player mode with AI opponent
- 🎯 Multiple difficulty levels (Easy, Medium, Hard)
- 👥 Two-player pass-and-play mode
- 🔄 Undo move functionality
- 🧠 Smart move handling (gravity-based disc placement)
- 🏆 Win and draw detection system
- 📊 Score tracking across matches
- 🎨 Modern and responsive UI
- ⚙️ Settings panel (theme, preferences)
