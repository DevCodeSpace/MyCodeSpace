# SecureVPN - Flutter VPN Application 🛡️

## High Level App Description

SecureVPN is a modern VPN application built with Flutter, featuring WireGuard protocol integration and a sleek, contemporary UI design. The app provides secure, fast, and reliable internet connectivity through multiple global server locations with real-time speed monitoring and connection analytics.

## How Many Locations We Are Providing

We currently provide **5 premium server locations**:

- 🇯🇵 **Japan** (Tokyo)
- 🇺🇸 **United States** (New York)
- 🇳🇱 **Netherlands** (Amsterdam)
- 🇷🇴 **Romania** (Bucharest)
- 🇵🇱 **Poland** (Warsaw)

## Key Features

- **WireGuard Protocol Integration** - Next-generation VPN security
- **Real-Time Speed Testing** - Automatic speed monitoring every 5 seconds
- **Modern Glassmorphism UI** - Contemporary dark theme with smooth animations
- **Live Connection Stats** - Download/Upload speeds displayed in real-time
- **IP Address Verification** - Shows current IP and location changes
- **Smart Server Selection** - Easy server switching with country flags
- **Auto-Reconnection** - Reliable connection with retry mechanisms
- **Cross-Platform Support** - Works on both iOS and Android
