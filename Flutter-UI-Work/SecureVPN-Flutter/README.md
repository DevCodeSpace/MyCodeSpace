# SecureVPN - Flutter VPN Application 🛡️

SecureVPN is a modern VPN application built with Flutter, featuring WireGuard protocol integration and a sleek, contemporary UI design. The app provides secure, fast, and reliable internet connectivity through multiple global server locations with real-time speed monitoring and connection analytics.

## How Many Locations We Are Providing

We currently provide **5 premium server locations**:

🇯🇵 **Japan** (Tokyo) </br>
🇺🇸 **United States** (New York) </br>
🇳🇱 **Netherlands** (Amsterdam) </br>
🇷🇴 **Romania** (Bucharest) </br>
🇵🇱 **Poland** (Warsaw) </br>

## Key Features

🛡 **WireGuard Protocol Integration** - Next-generation VPN security </br>
🛡 **Real-Time Speed Testing** - Automatic speed monitoring every 5 seconds </br>
🛡 **Modern Glassmorphism UI** - Contemporary dark theme with smooth animations </br>
🛡 **Live Connection Stats** - Download/Upload speeds displayed in real-time </br>
🛡 **IP Address Verification** - Shows current IP and location changes </br>
🛡 **Smart Server Selection** - Easy server switching with country flags </br>
🛡 **Auto-Reconnection** - Reliable connection with retry mechanisms </br>
🛡 **Cross-Platform Support** - Works on both iOS and Android </br>
